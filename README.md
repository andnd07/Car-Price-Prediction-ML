# Car Price Prediction using Machine Learning

##  Project Overview

This project focuses on building a Machine Learning model to predict the selling price of used cars based on various features such as mileage, engine capacity, fuel type, and more. The goal is to create a data-driven solution that helps estimate car prices accurately.

---

## Project Workflow

### STEP 1 - Import Libraries

Imported essential Python libraries like Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

### STEP 2 - Load Dataset & Understanding

Loaded the dataset and performed initial exploration to understand structure, features, and data types.

### STEP 3 - Data Cleaning

Handled missing values, corrected data formats, and removed inconsistencies.

### STEP 4 - Feature Engineering

Created a new feature **`car_age`** to improve model performance.

### STEP 5 - Exploratory Data Analysis (EDA)

Analyzed relationships between variables using statistical summaries and visualizations.

### STEP 6 - Outlier Detection & Removal

Identified and removed outliers to improve model accuracy.

### STEP 7 - Encoding

Converted categorical variables into numerical format using encoding techniques.

### STEP 8 - Feature Selection

Selected important features based on correlation analysis.

### STEP 9 - Train-Test Split

Split the dataset into training and testing sets (80/20 ratio).

### STEP 10 - Model Building

Trained a **Random Forest Regressor** model achieving an accuracy score of **0.87**.

### STEP 11 - Prediction

Used the trained model to predict car prices on unseen data.

### STEP 12 - Model Evaluation

Evaluated model performance using appropriate regression metrics.

### STEP 13 - Visualization

Visualized model results and feature relationships for better insights.

### STEP 14 - Model Interpretation

Analyzed feature importance to understand key factors affecting car prices.

### STEP 15 - Save Model

Saved the trained model using Pickle for future use and deployment.

### STEP 16 - Conclusion

The model successfully predicts car prices with good accuracy and can be further improved with more data and advanced techniques.
